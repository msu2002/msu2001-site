# بيان التحقق — أداة المصحف 1.0.0

## ما جرى التحقق منه

النص القرآني مصدره Tanzil الرسمي Uthmani 1.1. تضمّن ١١٤ سورة و٦٢٣٦ آية، وطابق منفذ بيانات المصدر كل نص XML الرسمي حرفيًا وملف التنزيل النصي الثاني مع سياسة البسملة. لا حذف لتكرارات نصية قرآنية مشروعة. تقرير المصدر المفصل مرفق في QURAN-DATA-VALIDATION.json ومصادره في QURAN-DATA-SOURCES.md.

نجح فحص أنواع المشروع، وتجميع جميع الوحدات المستقلة باستخدام esbuild للتأكد من ترابط الاستيرادات، وفحص syntax لكل وحدات JavaScript والعامل الخدمي. نجح سكربت التكامل بـ٥٦ assertion لعدد السور والآيات، وترتيبها، والبسملة، والتطبيع الخاص بالبحث، والescaping، والإعدادات، والعلامات والمدخلات غير الصالحة، ومواقيت مدن وحدود تاريخ، ووجود ملفات الحفظ ونطاق manifest والتبويبات والأذكار.

اختبر منفذ القارئ في Chromium بيانات ١١٤ سورة، و٢٨٦ آية للبقرة، والتطابق الحرفي لنص الفاتحة والافتتاح، والبحث مع إظهار ٤٠ ثم ٨٠ نتيجة وإجمالي صحيح، والانتقال بأرقام فارسية، والتكبير والعلامات وربط التفسير والتلاوة، وبسملات السور ١ و٩ و٩٥ و٩٧، وفتح الفهرس الجانبي على عرض ٣٩٠ وتنظيف المستمعات والمراقب.

اختبر منفذ الصلاة ٤٨ تركيبة مدينة/طريقة/مذهب، وحدود الشهر والسنة والكبيسة، وعدم إدخال الشروق ضمن الصلاة القادمة، واستقلال النتائج عن منطقة المضيف، وتوافق النصوص والتكرارات مع مصدر الأذكار الـ١٢. اختبر العدادات والحفظ والتصفير بتأكيد والتنظيف ورفض GPS والحساس عبر محاكاة API، لا عتادًا حقيقيًا.

اختبر منفذ الإعدادات بحاويات ومخازن وهمية، لا ببيانات إنتاج: تصدير/استيراد المخطط المحدد، ودمج دون تكرار، ورفض JSON تالف وتطبيق آخر وآية/تاريخ/إعداد غير صالح وحقول إضافية وملف أكبر من ٢ ميغابايت، وفشل الكتابة، وإلغاء المسح وتأكيده، وcleanup، ونتائج تجهيز offline المؤكدة وغير المؤكدة.

مراجعة تكامل قراءة فقط تحققت من exports وctx، ومصدر النص وعدم تطبيعه في العرض، والتفسير عبر textContent، ونطاق Service Worker وعدم حذف التخزين أو caches العامة. عولجت ملاحظاتها المحددة: عدم تأكيد الحفظ عند رفض localStorage، ربط القراءة المتصلة بالعرض، تحديث مواقيت الرئيسية والتاريخ وآية اليوم عند حدود اليوم والصلاة، تمييز جلب التفسير عن حفظه، ونسبة ملف الصوت للقارئ الجاري بدل تفضيل تغير أثناء التشغيل.

في المعاينة نجح تحميل HTML والوحدات بأنواعها الصحيحة. عولج توجيه Vite الخاص بمجلد /quran/ الذي كان يعرض fallback ورق؛ الحزمة النهائية لا تعتمد على Vite وتعمل بالمجلد ذي index.html على خادم ثابت. فحص المتصفح أظهر خمسة تبويبات، وService Worker فعليًا ضمن /quran/ فقط، وcache باسم خاص بالأداة، ودون overflow. قياس القارئ داخل إطارات Chromium بعرض ٣٩٠ و٨٢٠ أظهر ٧ آيات للفـاتحة ودون تمدد أفقي، وتنقلًا سفليًا للهاتف وجانبيًا للتابلت. هذه مقاسات محاكاة وليس أجهزة Apple.

## الحدود

لم تُختبر أداة المصحف على iPhone أو iPad فعلي أو Safari فعلي. لا يمكن اعتبار Chromium ضمانًا لتشغيل التلاوة في الخلفية أو أذون الحساسات/الموقع أو دوام التخزين في iOS. التلاوة بث خارجي؛ واختبار توفر ثلاث ملفات آية وقت العمل لا يضمن استمرار المصدر. التفسير API خارجي اختُبر CORS واستجابته، ولا يضمن استمراره أو أن رقم بطاقة الإصدار لا يتغير مستقبلًا.

تخزين المتصفح قابل للحذف؛ إشعار النجاح يتعلق بنتيجة كتابة أو تجهيز وقت الضغط لا ضمانًا دائمًا. المواقيت حسابية ويجب مراجعتها مع جدول البلد أو المسجد. النص مصحف نصي متجاوب وليس صور صفحات مطبوعة بنفس توزيعها. الأذكار مختارات موثقة؛ والخدمات الأخرى روابط خارجية معلنة. لا خدمة Push ولا أذان كامل موثوق عند إغلاق الموقع ودون اتصال.
