تنزيل الفيديو

أهلًا بك في Fahad Studio

مساحة عربية لإنشاء الفيديو، مجانًا ودون حساب أو علامة مائية.

  1. اجلب لقطاتكاستورد فيديو أو صورة أو صوت، ثم اضغط + لإضافته إلى المسار.
  2. اصنع إيقاعكاسحب المقاطع، قص الحواف، أو ضع المؤشر واضغط «تقسيم». عدّل التوقيت بدقة من الخصائص.
  3. أضف لمستكعناوين عربية متحركة وانتقالات ومزج صوتي. اسحب النص داخل المعاينة لتحديد موضعه.
  4. احفظ وشاركنزّل مشروعك مع وسائطه، أو صدّر الفيديو بالصيغة التي يدعمها متصفحك.
حدود النسخة الأولى

٤ مسارات، سرعة تشغيل عادية، تصدير مباشر بزمن الفيديو. دعم الملفات والترميز يعتمد على المتصفح. يتوفر تفريغ عربي تلقائي محلي عند إضافة فيديو. راجع الكلمات والتوقيت؛ تختلف الدقة حسب اللهجة والضوضاء. توليد الفيديو غير متاح.

الاختصارات: مسافة تشغيل · S تقسيم · Delete حذف · Ctrl/⌘ Z تراجع · الأسهم تحريك المؤشر. لا تُستخدم كاميرا أو ميكروفون ولا تُرفع ملفاتك إلى خادم.
